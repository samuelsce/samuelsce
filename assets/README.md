# Artes do perfil

As imagens `studio-header` e `studio-projects` adaptam a identidade do [portfólio de Samuel](https://github.com/samuelsce/Portfolio) ao README do GitHub. O mascote e o quarto isométrico reutilizam as ilustrações originais do próprio portfólio. A agenda e o painel são exemplos conceituais, não capturas de dados de clientes.

## Arquivos

- `.png`: imagens em resolução dupla, utilizadas pelo README.
- `.svg`: fontes vetoriais editáveis, com a fonte incorporada.
- Sufixo `-dark`: versão para leitores que utilizam tema escuro.

O elemento `picture` seleciona a imagem pelo tema. A versão clara também funciona como fallback. O conteúdo principal permanece em Markdown, com texto selecionável, links e um bloco expansível para o TCC.

## Identidade

- Papel: `#fff7fa`
- Rosa: `#ef75a3`
- Fundo rosa: `#f8dbe7`
- Texto: `#291b24`
- Detalhe: `#691b3e`
- Linha: `#e7cdd8`

A tipografia é **Space Grotesk**, sob a SIL Open Font License 1.1. A licença e o aviso de direitos autorais estão preservados em [Space-Grotesk-OFL.txt](Space-Grotesk-OFL.txt).

Para atualizar o perfil, edite `../README.md`. Para alterar uma arte, edite o SVG correspondente e exporte novamente o PNG com fundo transparente, em duas vezes as dimensões do `viewBox`.
