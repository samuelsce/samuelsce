## Olá, sou o Samuel

Sou **desenvolvedor Front-End em formação**, técnico em Desenvolvimento de Sistemas pela **Etec de Mauá** e graduando em Tecnologia da Informação pela **UNIVESP**. Gosto de transformar ideias em interfaces claras, responsivas e com personalidade.

Minha base é **HTML, CSS e JavaScript**. Hoje, construo projetos com **React, TypeScript e Next.js**, explorando desde experiências visuais em 3D até painéis conectados a dados e serviços. Meu foco é o Front-End, com aprendizado de back-end para compreender o produto de ponta a ponta.

Busco minha primeira oportunidade em desenvolvimento para contribuir com o time, aprender com a prática e evoluir com cada entrega.
